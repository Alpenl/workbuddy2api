## Runtime Files

| Path | Required | Description |
|---|---:|---|
| `config.json` | Yes | Server settings and API key; mount read-only at `/app/config.json` |
| `auths/` | Yes | OAuth credentials; the container user (UID 1000) must be able to write this directory |
| `data/` | Yes | Pool state; the container user (UID 1000) must be able to write this directory |

No database, Redis, migration, or required environment variable was detected. `TZ`, `WB2A_PORT`, and `WB2A_IMAGE` are optional Compose overrides.

## Docker Compose

```bash
cp config.example.json config.json
mkdir -p auths data
docker compose pull
docker compose up -d
docker compose ps
```

The Web console is available at `http://localhost:7863/`. The OpenAI-compatible base URL is `http://localhost:7863/v1`.

## Local Image Build

```bash
docker buildx build --platform linux/amd64 --load -t workbuddy2api:local .
```

## Docker Run

```bash
docker run -d \
  --name workbuddy2api \
  --user 1000:1000 \
  -p 7863:7863 \
  -v "$PWD/config.json:/app/config.json:ro" \
  -v "$PWD/auths:/app/auths" \
  -v "$PWD/data:/app/data" \
  ghcr.io/alpenl/workbuddy2api:latest
```

## Health Check

`GET /healthz` returns `200` only when at least one account is healthy. A fresh instance without an account intentionally reports `503` until OAuth login completes.

## Image Platforms

GitHub Actions publishes `linux/amd64` and `linux/arm64` images to `ghcr.io/alpenl/workbuddy2api` on pushes to `master` and `v*` tags.
